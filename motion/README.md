# Jennefer hero motion

15-second, 1200 × 880, 30 fps, silent loop for the landing page hero.

- Edit `HeroMotion.tsx` to change the scenes and timing.
- Preview with `npm run motion:studio`.
- Export with `npm run motion:render`.
- The hero uses `public/hero-motion-poster.png` as its loading poster. Regenerate it with `npx remotion still motion/index.ts JenneferHero public/hero-motion-poster.png --frame=215` after changing the visual design.
